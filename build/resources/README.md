# Risorse Packaging

Questa cartella contiene le risorse usate per il packaging Windows.

File previsti:

- `icon.ico`: icona applicazione usata da executable, installer e collegamenti

Puoi sostituire `icon.ico` con la tua icona definitiva mantenendo lo stesso nome file.

Per una resa migliore in Windows:

- includi almeno misure 16x16, 32x32, 48x48, 256x256
- usa un file `.ico` multi-size
- mantieni il nome `icon.ico` per non dover aggiornare la configurazione packaging
